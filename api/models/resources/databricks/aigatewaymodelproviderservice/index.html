AiGatewayModelProviderService

laktory.models.resources.databricks.AiGatewayModelProviderService ¤

Bases: AiGatewayModelProviderServiceBase

Databricks AI Gateway model provider service

Unity Catalog governed connection to an external model provider (OpenAI, Azure OpenAI, Anthropic, Amazon Bedrock, Gemini, custom, etc.) and the provider models that model services can route to.

Examples:

import io

from laktory import models

service_yaml = '''
parent: schemas/dev.ai
model_provider_service_id: openai_prod
comment: OpenAI production account
config:
  provider_type: EXTERNAL_MODEL_PROVIDER_TYPE_OPENAI
  targets:
  - model: gpt-5
    native_api_types:
    - openai/v1/chat/completions
  openai:
    direct:
      api_key:
        secret_reference:
          name: secrets/dev.ai.openai_api_key
'''
service = (
    models.resources.databricks.AiGatewayModelProviderService.model_validate_yaml(
        io.StringIO(service_yaml)
    )
)
