laktory.models.resources.databricks.AccountNetworkPolicy ¤

Bases: AccountNetworkPolicyBase

Databricks account network policy (account level)

Network access rules (serverless egress destinations, ingress) that workspaces of the account can be bound to. Requires an account-level provider.

Examples:

import io

from laktory import models

policy_yaml = '''
network_policy_id: restricted-egress
egress:
  network_access:
    restriction_mode: RESTRICTED_ACCESS
    allowed_internet_destinations:
    - destination: pypi.org
      internet_destination_type: DNS_NAME
    policy_enforcement:
      enforcement_mode: ENFORCED
workspace_ids:
- 1234567890123456
'''
policy = models.resources.databricks.AccountNetworkPolicy.model_validate_yaml(
    io.StringIO(policy_yaml)
)
